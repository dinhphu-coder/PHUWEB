# PHUWEB Project

## Mô tả
Dự án web demo cơ bản sử dụng HTML, CSS và JavaScript thuần túy (Vanilla JS).

## Cấu trúc
- `public/index.html` - Trang chính
- `public/style.css` - Stylesheet
- `public/script.js` - JavaScript interactivity

## Chạy dự án
Mở `public/index.html` trong trình duyệt.

## Tính năng chính
1. **Header**: Gradient background với tiêu đề và mô tả
2. **Hero section**: Call-to-action button với animation
3. **Features grid**: 3 cards với icons mô tả tính năng
4. **Footer**: Copyright information
5. **Interactions**:
   - Smooth scroll khi click vào anchor links
   - Header fade effect khi scroll
   - Feature card hover effects
   - Fade-in animation khi element xuất hiện

## Customize
- Thay đổi màu sắc trong `style.css`
- Thêm thêm features cards trong HTML
- Mở rộng JavaScript cho nhiều interactions hơn

## Build & Deploy
Dự án statis - có thể deploy lên bất kỳ hosting nào (Netlify, Vercel, GitHub Pages...).
