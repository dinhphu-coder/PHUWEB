# PHUWEB - Web Demo Project

A basic web demonstration project featuring:

## Struktur Dự án
```
d:PHUWEB/
├── public/         # Files served to browser
│   ├── index.html  # Trang chính
│   ├── style.css   # Stylesheet
│   └── script.js   # JavaScript interactivity
└── src/            # Source files (nếu có)
```

## Chạy dự án
Mở file `public/index.html` trong trình duyệt web bất kỳ.

## Tính năng
- **Giao diện đẹp**: Sử dụng gradient colors và modern design
- **Responsive**: Hoạt động tốt trên điện thoại và desktop
- **Interactive**: Hover effects, scroll animations, smooth scrolling
- **Accessible**: Semantic HTML và ARIA-friendly

## Công nghệ sử dụng
- HTML5 semantic structure
- CSS3 với gradients, flexbox, grid
- Vanilla JavaScript (DOM manipulation, Intersection Observer)
- Mobile-first responsive design
